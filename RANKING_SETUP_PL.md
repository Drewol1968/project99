# PROJECT 99 — uruchomienie rankingu globalnego

Frontend rankingu jest już gotowy. Do uruchomienia potrzebny jest darmowy projekt Supabase.

1. Utwórz projekt na Supabase.
2. W Authentication włącz **Anonymous Sign-Ins**.
3. Otwórz SQL Editor i uruchom cały plik `supabase-schema.sql`.
4. W ustawieniach projektu skopiuj:
   - Project URL
   - Publishable key / anon key
5. Wpisz je w pliku `ranking-config.js`.

Nie wpisuj do aplikacji klucza `service_role` ani żadnego sekretnego klucza.
